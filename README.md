# Le Sporting Saint-Tropez · Site Vitrine Officiel

> Site vitrine moderne, chaleureux et haut de gamme pour **Le Sporting**, brasserie-pizzeria emblématique de la Place des Lices à Saint-Tropez.

---

##  Présentation

- **Établissement** : Le Sporting by Papüm
- **Adresse** : 42 Place des Lices · Boulevard Vasserot, 83990 Saint-Tropez
- **Ambiance** : Brasserie conviviale et festive, décor boisé, terrasse sous les platanes & oliviers
- **Cuisine** : Cuisine méditerranéenne maison, pizzas au feu de bois, tataki de thon, burger Papüm, pasta à la truffe
- **Horaires** : Ouvert 7j/7 de 08h00 à 03h00 du matin (service continu 8h - 23h)

---

## 🛠️ Stack Technique

- **Framework** : React 19
- **Build Tool** : Vite
- **Styles** : CSS Modules & Vanilla CSS (Design system sur mesure aux couleurs de la carte `#b1af8a`)
- **Typographie** : *Cinzel* (Serif luxe), *Inter* (Sans moderne), *Insta Story Signature* (Script officiel)
- **Animations** : Effet de lumière sur le logo officiel, carrousel d'avis interactif, preloader avec splash screen

---

##  Installation & Lancement

```bash
# 1. Cloner le dépôt
git clone https://github.com/RayanBKL/lesporting.git
cd lesporting

# 2. Installer les dépendances
npm install

# 3. Lancer en local
npm run dev

# 4. Compiler pour la production
npm run build
```

## 📸 Structure des Ressources

- `/public/images/` : Photos optimisées en haute définition utilisées sur le site
- `/public/logo-official.png` : Logo vectoriel transparent avec antialiasing
- `/Photos_Organisees/` : Ensemble des photographies sources triées et classées par catégories
- `/Insta Story Signature.ttf` : Typographie manuscrite officielle
